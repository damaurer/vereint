# Benutzerhandbuch

Das Benutzerhandbuch beschreibt die App Schritt für Schritt mit echten
Bildschirmfotos, getrennt nach Rolle:

| Leitfaden | Für |
| :--- | :--- |
| [Erste Schritte](https://github.com/damaurer/vereint/blob/develop/docs/handbuch/01-erste-schritte.md) | Alle: registrieren, anmelden, Profil, Zwei-Faktor-Anmeldung, App installieren, Push |
| [Mitglied](https://github.com/damaurer/vereint/blob/develop/docs/handbuch/02-mitglied.md) | Events, Chat, per Barcode bezahlen, Guthaben, Moments mit Fotos und Videos, Statistik |
| [Vorstand](https://github.com/damaurer/vereint/blob/develop/docs/handbuch/03-vorstand.md) | Kasse, Events vorbereiten, Katalog, Kommunikation, Moment-Typen, Kiosk-Geräte |
| [Administration](https://github.com/damaurer/vereint/blob/develop/docs/handbuch/04-administration.md) | Mitglieder einladen und verwalten, Rollen, Thekentablet, Passwort zurücksetzen |
| [Thekenterminal](https://github.com/damaurer/vereint/blob/develop/docs/handbuch/05-thekenterminal.md) | Kiosk-Modus mit PIN, Striche erfassen und korrigieren, Runden |
| [Gast](https://github.com/damaurer/vereint/blob/develop/docs/handbuch/06-gast.md) | Über einen Gast-Link am Event-Chat teilnehmen |

Das Handbuch liegt unter
[`docs/handbuch/`](https://github.com/damaurer/vereint/tree/develop/docs/handbuch).
Die Bildschirmfotos erzeugt ein Playwright-Skript
([`scripts/handbook`](https://github.com/damaurer/vereint/tree/develop/scripts/handbook)),
damit sie nach Änderungen der Oberfläche neu aufgenommen werden können.

Einen kurzen Überblick über die Funktionen ohne Bildschirmfotos gibt die Seite
[Funktionen](Funktionen); wer was darf, steht unter
[Rollen und Berechtigungen](Rollen-und-Berechtigungen).
