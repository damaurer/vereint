# Benutzerhandbuch

Das Benutzerhandbuch beschreibt die App Schritt für Schritt mit echten
Bildschirmfotos, getrennt nach Rolle:

- Erste Schritte (Anmelden, App installieren, Push einschalten)
- Mitglied
- Vorstand
- Administration
- Thekenterminal
- Gast

Es entsteht in [Pull Request #14](https://github.com/damaurer/vereint/pull/14)
unter `docs/handbuch/`. Die Bildschirmfotos erzeugt ein Playwright-Skript
(`scripts/handbook`), damit sie bei Änderungen der Oberfläche neu aufgenommen
werden können.

Sobald der Pull Request gemerged ist, liegt das Handbuch unter
[docs/handbuch](https://github.com/damaurer/vereint/tree/develop/docs/handbuch).
Bis dahin ist der aktuelle Stand im Branch des Pull Requests zu finden.

Einen kurzen Überblick über die Funktionen ohne Bildschirmfotos gibt die Seite
[Funktionen](Funktionen); wer was darf, steht unter
[Rollen und Berechtigungen](Rollen-und-Berechtigungen).
