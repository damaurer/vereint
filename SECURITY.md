# Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern
vertraulich über GitHub: Reiter **Security** → **Report a vulnerability**
(private vulnerability reporting). Beschreibe kurz, was betroffen ist und wie
sich das Problem nachstellen lässt.

Vereint ist ein Hobbyprojekt. Es gibt keine zugesicherten Reaktionszeiten, jede
Meldung wird aber gelesen und so schnell wie möglich bearbeitet.

Unterstützt wird nur der aktuelle Stand von `main`.

Wie Vereint Daten schützt (Verschlüsselung, Schlüssel, Härtung), steht in
[docs/betrieb/sicherheit-und-schluessel.md](docs/betrieb/sicherheit-und-schluessel.md).
